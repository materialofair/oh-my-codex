# Multi-Agent Research

Codex-native technical research using read-only child agents for architecture, risk, and documentation perspectives.

## Usage

```text
使用 multi-model-research 分析 <你的问题>
```

## What It Does

- Clarifies research scope and evaluation dimensions
- Uses local repository evidence where available
- Uses official docs for version-sensitive claims
- Dispatches `explorer`, `reviewer`, and `docs-researcher` as needed
- Produces a source-backed ResearchPack

## Output

- Topic and sources
- Findings by dimension
- Options and tradeoffs
- Recommendation
- Validation plan
- Open questions

## Notes

Despite the historical skill name, the current workflow is multi-agent rather than external-model based.
